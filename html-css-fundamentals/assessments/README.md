# Assessment 03: Practical HTML & CSS Challenge

<badge color="warning">Intermediate</badge>

**Total: 60 Marks**

## Challenge: Build a Student Information Website

### Project Description

Create a responsive student information website using HTML5 and CSS3.

### Requirements

Your website must include:

**1. Navigation Bar — 10 Marks**

- Website logo.
- Home link.
- About link.
- Courses link.
- Contact link.

**2. Hero Section — 10 Marks**

- Main heading.
- Short description.
- Background image or color.
- Call-to-action button.

**3. About Section — 10 Marks**

- Section heading.
- At least two paragraphs.
- Relevant image.

**4. Courses Section — 10 Marks**

- At least three course cards.
- Course title.
- Course description.
- Suitable layout.

**5. Contact Section — 5 Marks**

- Name input.
- Email input.
- Message field.
- Submit button.

**6. Responsive Design — 10 Marks**

- Website must adapt to mobile screens.
- Navigation and cards must remain usable.
- No unwanted horizontal scrolling.

**7. Code Organization — 5 Marks**

- Separate HTML and CSS files.
- Meaningful class names.
- Proper indentation.
- Organized folders.
