#  HTML & CSS Practical Exercises

Welcome to the practice zone!

This folder contains practical activities designed to help you apply the concepts covered in the Structure & Style curriculum.

## Instructions

- Complete the exercises in order.
- Write your own HTML and CSS.
- Use meaningful file and class names.
- Test your work in a browser.
- Keep your code organized.
- Do not simply copy examples—experiment and learn.

---

## Exercise 01: Your First Webpage

<badge color="success">Beginner</badge>

**Topics:** HTML introduction and elements.

### Requirements

Create an HTML webpage containing:

- A page title.
- One main heading.
- Two paragraphs introducing yourself.
- An image.
- A link to your favourite website.
- A list of three hobbies.

**Expected files:**

```text
exercise-01/
└── index.html
```

## Exercise 02: Build a Student Profile

<badge color="success">Beginner</badge>

**Topics:** HTML elements and CSS introduction.

### Requirements

Create a student profile page containing:

- A profile image.
- Full name.
- Course or area of study.
- Short biography.
- Three skills.
- Contact button.

Apply CSS styling to make the profile attractive.

## Exercise 03: Create a Registration Form

<badge color="success">Beginner</badge>

**Topics:** HTML forms.

### Requirements

Create a student registration form with:

- Full name.
- Email address.
- Password.
- Gender selection.
- Course selection.
- Date of birth.
- Terms and conditions checkbox.
- Submit button.

Use suitable HTML input types and labels.

## Exercise 04: Design a Navigation Bar

<badge color="success">Beginner</badge>

**Topics:** CSS selectors and Flexbox.

### Requirements

Create a navigation bar containing:

- Website logo.
- Home link.
- About link.
- Services link.
- Contact link.
- Login button.

Use Flexbox to align the items.

Add a hover effect to the links.

## Exercise 05: Create Product Cards

<badge color="warning">Intermediate</badge>

**Topics:** Box Model and CSS Grid.

### Requirements

Create a product section with at least six product cards.

Each card should contain:

- Product image.
- Product name.
- Short description.
- Price.
- View Product button.

Use:

- Padding and margin.
- Borders and border radius.
- Box shadows.
- CSS Grid.
- Hover effects.

## Exercise 06: Create a Responsive Landing Page

<badge color="warning">Intermediate</badge>

**Topics:** Responsive design, Flexbox, and Grid.

### Requirements

Create a landing page with:

1. Navigation bar.
2. Hero section.
3. About section.
4. Services section.
5. Contact section.
6. Footer.

Your page must work on:

- Mobile phones.
- Tablets.
- Desktop computers.

## Exercise 07: Build a Photo Gallery

<badge color="warning">Intermediate</badge>

**Topics:** CSS Grid and responsive images.

### Requirements

Create an image gallery containing at least nine images.

Add:

- Consistent image dimensions.
- Rounded corners.
- Hover effects.
- Grid layout.
- Responsive columns.

## Exercise 08: Create a Personal Portfolio

<badge color="danger">Challenge</badge>

**Topics:** All HTML and CSS modules.

### Requirements

Build a personal portfolio website with:

- A professional hero section.
- About me.
- Skills.
- Education.
- Projects.
- Contact information.
- Footer.

Your portfolio should have a consistent color scheme, readable typography, and responsive layout.
