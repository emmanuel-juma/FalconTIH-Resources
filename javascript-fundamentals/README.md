## 01. About This Repository

JavaScript is one of the core technologies of modern web development.

This repository provides a practical introduction to programming with JavaScript, progressing from basic syntax to DOM manipulation, asynchronous programming and API integration.

The emphasis is on understanding how code works, not simply memorising syntax.

## 02. Learning Objectives

Learners will develop the ability to:

- Understand JavaScript execution.
- Work with variables and data types.
- Implement conditional logic.
- Write reusable functions.
- Manipulate arrays and objects.
- Understand scope and closures.
- Work with the Document Object Model.
- Handle browser events.
- Understand asynchronous programming.
- Fetch and process API data.
- Organise code using modules.
