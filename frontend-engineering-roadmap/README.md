## 01. Introduction

The Frontend Engineering Roadmap is a structured learning pathway designed to guide aspiring developers through the technologies, concepts and engineering practices involved in building modern web applications.

This repository serves as the central reference point for the entire frontend learning programme.

## 02. The Learning Path

| Phase | Subject | Outcome |
|---|---|---|
| 01 | Web Foundations | Understand the web |
| 02 | HTML5 | Structure documents |
| 03 | CSS3 | Design responsive interfaces |
| 04 | JavaScript | Develop programming logic |
| 05 | Git & GitHub | Manage source code |
| 06 | React | Build interactive interfaces |
| 07 | TypeScript | Develop type-safe applications |
| 08 | APIs | Integrate external services |
| 09 | Deployment | Publish applications |
| 10 | Portfolio | Demonstrate engineering skills |

## 03. Learning Philosophy

Our approach follows:

**Understand → Explore → Implement → Practise → Build → Review**

## 04. Competencies

By completing this roadmap, learners should be able to:

- Understand web architecture and browser fundamentals.
- Build responsive and accessible interfaces.
- Write maintainable JavaScript.
- Develop component-based applications.
- Work with APIs and asynchronous data.
- Use version control professionally.
- Deploy and document software projects.
