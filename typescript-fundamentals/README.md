## 01. About This Course

TypeScript extends JavaScript by introducing a static type system.

This repository provides a practical pathway into TypeScript, explaining how types improve code clarity, development workflows and application maintainability.

## 02. Learning Objectives

- Understand TypeScript and its relationship with JavaScript.
- Configure a TypeScript environment.
- Work with primitive and complex types.
- Use type annotations.
- Define interfaces and type aliases.
- Type functions.
- Understand unions and intersections.
- Work with generics.
- Apply type narrowing.
- Integrate TypeScript with React.
