## 01. Introduction

React is a JavaScript library for building user interfaces.

This repository introduces component-based development and the core concepts required to build maintainable React applications.

Learners will move from their first React component to building interactive applications that consume external APIs.

## 02. Learning Objectives

- Understand React and component architecture.
- Configure a React development environment.
- Write and understand JSX.
- Build reusable components.
- Pass data using props.
- Manage state.
- Handle events and forms.
- Understand React Hooks.
- Work with API data.
- Implement application routing.
- Organise frontend applications.
