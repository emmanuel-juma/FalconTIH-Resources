## 01. About the Lab

The Frontend Project Labs repository provides a collection of structured engineering challenges designed to help learners develop practical programming and problem-solving abilities.

Each project introduces a defined problem and challenges learners to design, implement, test and document a working solution.

This is where theoretical knowledge becomes engineering experience.

## 02. Laboratory Objectives

Learners will develop the ability to:

- Translate requirements into working interfaces.
- Plan and structure frontend applications.
- Apply programming concepts to practical problems.
- Build reusable components.
- Integrate external APIs.
- Debug and improve code.
- Test application functionality.
- Document and deploy projects.

## 07. Project Evaluation

| Criterion | Focus |
|---|---|
| Requirements | Completeness |
| Functionality | Correct behaviour |
| Architecture | Code organisation |
| UI/UX | Usability |
| Responsiveness | Device compatibility |
| Accessibility | Inclusive interaction |
| Documentation | Technical clarity |

## 08. Submission Guidelines

Every project submission should include:

- A GitHub repository.
- A descriptive README.
- Source code.
- Screenshots or a demonstration.
- A live deployment where applicable.
- A summary of challenges and solutions.
